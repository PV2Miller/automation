# Security Policy

## Reporting a Vulnerability

Please report security concerns privately to the repository owner.

Do not publicly disclose vulnerabilities until they have been reviewed and remediated.

## Secrets Management

Never commit:

- API keys
- Passwords
- Access tokens
- Certificates
- Private keys
- Recovery phrases

Secrets should be stored using:

- Azure Key Vault
- Environment variables
- Other approved secret-management systems

## Security Principles

This repository follows these principles:

- Least Privilege
- Defense in Depth
- Secure by Default
- Approval Before Execution

## Supported Versions

Only the current main branch is supported.
